# Twitter Static Clone

A fully responsive **Twitter UI clone** built using **HTML & CSS** only.  
This project focuses on layout design, responsiveness, and replicating the visual style of Twitter.

---

## 🚀 Features
- Clean and modern Twitter-like interface
- Fully responsive across desktop, tablet, and mobile
- Built with semantic HTML5 and modern CSS3
- Includes navigation bar, profile section, and feed layout

---

## 🛠 Tech Stack
- **HTML5** – For structure and markup
- **CSS3** – For styling and responsiveness (Flexbox & Grid)
